# Чек-лист bootstrap

Нормативный документ `harness-init`. Определяет минимальный набор и порядок
проверки.

## 1. До scaffold

- [ ] опрос проведён, ответы сохранены;
- [ ] научная работа, данные, отчёты и воспроизводимость зафиксированы или
      явно пропущены;
- [ ] домен, стек, команды и задачи зафиксированы;
- [ ] для разработки указаны greenfield/brownfield и специфика;
- [ ] пользователю названа отдельная команда `/dev-spec-chain` для SDD;
- [ ] решение по пополнению библиотеки навыков зафиксировано;
- [ ] стартовые навыки выбраны из реализованных;
- [ ] `bootstrap-plan.html` собран;
- [ ] план утверждён пользователем, статус `approved`;
- [ ] понятно, какие файлы будут созданы и какие пропущены.

## 2. Минимальный scaffold

| Путь | Назначение |
|---|---|
| `profile.yml` | проект, домен, команды, навыки |
| `AGENTS.md` | правила, команды и гейты |
| `docs/research/` | research ledger |
| `docs/reviews/` | HTML-ревью |
| `docs/audits/` | отчёты аудита |
| `docs/rules/registry.yml` | реестр правил |
| `.pre-commit-config.yaml` | локальные хуки |
| `.github/workflows/ci.yml` | CI, если выбран |

## 3. Ограничения

- Существующие файлы не перезаписываются без `--force`.
- Пустая команда тестов не считается проверкой.
- CI создаётся только при `ci=github`.
- Секреты и проектные данные в шаблоны не попадают.
- Установка зависимостей и commit/push не выполняются.

## 4. Проверка

```bash
python scripts/check_bootstrap.py --root /path/to/repo
python scripts/check_bootstrap.py --root /path/to/repo --json
```

Проверяется:

- обязательные файлы и каталоги;
- `profile.yml`: project, domain, commands, skills;
- `profile.yml`: project_mode, science_work, science_outputs, sdd, если
  заполнены;
- `ci=github` требует workflow;
- `docs/rules/registry.yml` содержит `version: 1`;
- нет `{{...}}` и `TODO`;
- код завершения `0`.

## 5. Приёмка

- [ ] `bootstrap-plan.html` имеет `approved`;
- [ ] `apply` создал минимальный набор;
- [ ] повторный `apply` не перезаписал файлы;
- [ ] `check_bootstrap.py` проходит;
- [ ] `bootstrap-report.md` перечисляет созданное и пропущенное;
- [ ] стартовые навыки присутствуют в `profile.yml`.

## 6. Ошибки

- scaffold без утверждения;
- bootstrap выдан за настройку SDD вместо `/dev-spec-chain`;
- пропущены научные данные, отчёты или специфика разработки;
- рекомендация proposed-навыка как установленного;
- перезапись `AGENTS.md`;
- CI с пустыми командами;
- новый навык добавлен без research/review;
- `check_bootstrap.py` не запускался;
- отчёт не перечисляет пропущенные файлы.
