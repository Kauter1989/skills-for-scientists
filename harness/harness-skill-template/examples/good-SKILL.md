# harness-example — эталон заполнения

Проверяет, что навык следует контракту библиотеки, и показывает полный набор
разделов.

## Когда применять

- добавлен новый навык и нужно проверить структуру;
- существующий навык приводят к контракту;
- перед ревью нужен отчёт валидатора.

## Когда не применять

- нужна оценка пользы навыка — это `harness-skill-eval`;
- нужен аудит всей библиотеки — это `harness-skill-audit`.

## Вход

- путь к каталогу навыка;
- ожидаемый домен.

## Процедура

1. Запустить `validate_skill.py`.
2. Разобрать ошибки и предупреждения.
3. Исправить структуру и ссылки.
4. Повторить проверку до нуля ошибок.

## Выход

- отчёт валидатора с кодом завершения;
- список исправлений.

## Доказательства

- код завершения `0`;
- в отчёте нет ошибок;
- пример из `examples/` существует.

## Границы

- не проверяет смысл и качество процедуры;
- не заменяет ревью и оценку эффективности.

## Типовые ошибки

- запуск на шаблоне вместо созданного навыка;
- пустой `examples/`;
- ссылка на несуществующий файл.

## QA

- [ ] имя совпадает с каталогом;
- [ ] обязательные разделы на месте;
- [ ] отчёт валидатора без ошибок.
