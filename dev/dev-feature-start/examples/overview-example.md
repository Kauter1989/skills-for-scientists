## Цель

Дать возможность отправить ссылку на запись человеку без входа в систему.

## Границы

- создание ссылки владельцем;
- срок жизни и отзыв;
- отказ при доступе к чужой записи.

## Не входит

- редактирование записи по ссылке;
- массовые ссылки;
- аналитика переходов.
