Инварианты

не отключаются ни одним подходом

#ИнвариантПроверка
I1Подробное описание: expected / actual, окружение, версия, шаги, входы, логиполя repro.json
I2Воспроизводимость: не менее 3 прогонов с одинаковым результатомprobe.json
I3Минимальный вход, каждый остаток обоснованminimal_case, removed
I4Падающий автотест до фиксаtest.path, test.name, red_output
I5Падение соответствует заявленному symptomfailure_matches_symptom
I6Диагноз: гипотезы с evidence, confidence и следующим probediagnosis.hypotheses
I7Фикс не начинается до красного гейтаstatus и порядок шагов
I8Артефакты в docs/bugs/<id>/манифест и файлы
I9Недоверенные команды не запускаются автоматическиявное решение пользователя
