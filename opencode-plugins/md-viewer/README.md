# opencode-md-panel

Панель Markdown для OpenCode Desktop: список `.md`-файлов проекта, предпросмотр
и встроенный редактор с сохранением на диск.

## Что делает

- Боковая панель в сессии со всеми Markdown-файлами рабочей папки.
- Поиск по имени файла, обновление списка.
- Рендер Markdown так же, как в ленте сообщений OpenCode.
- Кнопка **Edit** — редактирование, **Save** (или `Ctrl+S`) — запись файла.
- **Preview** — возврат к просмотру, **Revert** — отмена несохранённых правок.
- **Reload** — перечитать файл с диска.

## Как открыть

- Палитра команд: **Open Markdown panel**.
- Меню **+** боковой панели сессии: **Markdown**.
- Панель привязана к текущей папке проекта; при смене проекта список
  перестраивается.

## Сборка

```bash
bun install
bun run build
```

GUI-часть собирается в `dist/gui-experimental.cjs`. Серверная часть
загружается напрямую из `src/index.ts`.

## Подключение

Добавьте каталог плагина в `~/.config/opencode/opencode.json`:

```jsonc
{
  "plugins": ["<путь-к-репозиторию>/skills/opencode-plugins/md-viewer"]
}
```

Если плагин скопирован в глобальный каталог, путь будет
`~/.config/opencode/plugins/opencode-md-panel`.

После изменения `dist/` плагин перезагружается автоматически. Если панель не
появилась в уже открытом окне, откройте **Settings → Extensions → Plugins →
Reload** или перезапустите OpenCode.

## Безопасность

Серверная часть читает и пишет только файлы с расширениями `.md`, `.markdown`,
`.mdx`, `.mdown`, `.mkd` внутри папки текущей сессии. Выход за пределы папки
через `..` или абсолютный путь отклоняется. Лимит — 4 МБ на файл.

## Устройство

- `src/rpc.ts` — контракт RPC (`list`, `read`, `write`).
- `src/index.ts` — серверная часть: обход папки, чтение и запись.
- `src/gui.tsx` — панель Desktop: список, предпросмотр, редактор.
