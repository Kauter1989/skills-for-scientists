# opencode-quota

Сторонний плагин квот и расхода токенов. В этой папке нет исходников: он
устанавливается из npm и подключается по имени пакета.

| Поле | Значение |
|---|---|
| Пакет | `@slkiser/opencode-quota` |
| Версия на момент снимка | `6.0.0` |
| Лицензия | MIT |
| Репозиторий | https://github.com/slkiser/opencode-quota |
| Node | `^22.13.0` или `>=23.4.0` |

## Подключение

В `~/.config/opencode/opencode.json`:

```jsonc
{
  "plugins": ["@slkiser/opencode-quota"]
}
```

OpenCode разрешает npm-плагин и кэширует его. Если в вашей установке
автоматическая установка отключена, поставьте пакет глобально:

```bash
bun add -g @slkiser/opencode-quota
# или
npm install -g @slkiser/opencode-quota
```

## Проверка

- В интерфейсе появляется индикатор квоты.
- Инструмент `quota_status` возвращает диагностику.
- Провайдеры квоты настраиваются через настройки плагина или
  `opencode-quota` CLI.

## Ограничения

- Плагин сторонний; его поведение и формат данных могут меняться между
  версиями.
- Для приватных провайдеров нужны свои ключи; они не хранятся в этом
  репозитории.
- Без сети индикатор может показывать `missing` или последний известный
  снимок.
