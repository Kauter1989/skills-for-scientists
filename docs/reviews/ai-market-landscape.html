01

Проблема и границы

Запрос «покажи динамику ИИ-рынка РФ и мира по домену, услугам и ПАК» сегодня превращается в пересказ статей. Числа в таком пересказе не воспроизводимы, сравнение РФ и мира делается на абсолютах при разнице масштабов на порядок, а «в РФ этого нет» утверждается без порога и без источника. Навык фиксирует таксономию, снимок компаний с URL и датой, метки качества у каждой метрики и детерминированный расчёт динамики и пробелов.

Входит в задачу

  • таксономия доменов, услуг и классов ПАК;
  • снимок компаний РФ и мира с URL и датой;
  • динамика по трём осям между снимками;
  • сравнение долей, а не абсолютов;
  • список пробелов РФ с порогом;
  • автономный HTML и JSON-анализ.

Не входит

  • оценка компаний и менеджмента;
  • ёмкость рынка в рублях и долларах;
  • прогноз выручки и капитализации;
  • персональные данные;
  • юридическая проверка контрагента;
  • полный охват закрытых баз (Crunchbase, РАР).

04

Синтез и предлагаемый дизайн

Паттерн зрелых проектов: сначала объявленная таксономия и методичка, затем версионируемый снимок, отдельный расчёт и отчёт с метками качества. Отсюда дизайн «профиль → сбор → анализ → HTML → проверка».

landscape.md→ collect.py→ analyze.py→ build_report.py→ check_report.py

Вход

Профиль .ai-market-landscape/landscape.md: когорты, таксономия, период, источники. Плюс рабочий каталог со снимками companies.json.

Выход

companies-YYYY-MM-DD.json, analysis.json, автономный report.html с двумя независимыми блоками «РФ» и «Мир» и блоком «Пробелы».

Артефакты навыка

  • SKILL.md — триггеры, процедура, границы;
  • references/ — method.md, metrics.md, taxonomy.md, sources.md, report-contract.md;
  • scripts/ — profile.py, collect.py (сеть), analyze.py, build_report.py, check_report.py;
  • templates/landscape.md — форма профиля;
  • examples/ — профиль, снимок с реальными компаниями и URL, analysis.json, готовый report.html.
companies.json {
  "snapshotDate": "2026-11-06",
  "companies": [{ "id": "...", "cohort": "RF|WORLD", "roles": ["developer","integrator"],
    "domains": [...], "services": [...], "pak": "none|ai_component|ai_system|ai_software_package",
    "evidence": [{"url": "https://...", "retrievedAt": "2026-11-06", "kind": "company_site"}],
    "quality": "measured|derived|estimated|expert|missing" }]
}

06

Метрики и план проверки

AIC — число компаний, measured OW — доля по услуге, derived PSS — доля ПАК, derived GAP — разница долей при ≥10 компаниях Gini — концентрация ролей
  1. python scripts/analyze.py examples/example-companies.json --strict — расчёт без ошибок, у каждой метрики метка качества.
  2. python scripts/build_report.py --example -o examples/example-report.html --strict — отчёт собирается.
  3. python scripts/check_report.py examples/example-report.html — ноль внешних ресурсов, у каждой компании URL.
  4. python harness/harness-skill-template/scripts/validate_skill.py reports/ai-market-landscape — зелёный.
  5. python scripts/collect.py --source openrouter --out ... — реальный снимок, каждая запись с evidence.
