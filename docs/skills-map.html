Внутри доменных папок каталоги плоские: один каталог — один навык. При установке копируется dev/dev-pr-report-html в ~/.config/opencode/skill/dev-pr-report-html; папка-домен в имя навыка не входит.

Установка

  • домен: скопировать навык из dev/, sci/ или harness/
  • отчёты: скопировать из reports/
  • личная: ~/.config/opencode/skill/<name>/
  • проектная: .opencode/skill/<name>/

Правило библиотеки

Скилл без артефакта-доказательства — это промпт. Каждый новый навык добавляет вход, выход и способ проверить, что выход настоящий.
