## 1. Задача

Собрать персональный научный дайджест за выбранный период: по сохранённым
направлениям пользователя найти публикации в журналах Q1, конференциях A* и
журналах Q2, синтезировать ключевые темы, собрать новые датасеты и объяснить
критерии отнесения работы к A*/Q1. Результат — один автономный HTML-файл.

**Не входит в задачу:** замена систематического обзора, полный full-text
скрининг, оценка конкретного автора, покупка доступа к Scopus/Web of Science,
автоматическое выставление квартилей без источника и проверка истинности
аннотаций.

## 5. Синтез

- **Повторяющиеся паттерны:** научный дайджест — это не список ссылок, а
  протокол поиска, явные критерии, категории площадок, синтез и ссылки на
  доказательства; ranking — фильтр, а не оценка качества статьи.
- **Противоречия:** SCImago даёт квартиль в конкретной предметной категории и
  году, а не «Q1 вообще»; одна и та же статья может быть Q1 в одной категории
  и Q2 в другой. ICORE A* относится к конференции, а не к статье.
- **Пробелы:** открытые API не дают одновременно квартиль и A*; нужен
  композитный слой: OpenAlex/DataCite + кэш SJR + кэш ICORE + явная методика.
- **Что подтверждено:** PRISMA/PRISMA-S и SLR-гайдлайны требуют
  воспроизводимого протокола; SJR и ICORE являются признанными ranking-
  источниками; OpenAlex/DataCite дают достаточные метаданные для скрининга.
- **Что является решением автора:** период 6 месяцев по умолчанию, лимит
  результатов, рубрики Q1/A*/Q2 и формат HTML — продуктовые параметры.

## 6. Выводы для дизайна

| Решение | Основание | Альтернатива | Почему не она |
|---|---|---|---|
| MD-профиль с направлениями и периодом | запрос пользователя; PRISMA-S | настройки в JSON | пользователь просил правимый и запоминаемый MD |
| Показывать направления и период перед запуском, сохранять после подтверждения | PRISMA (протокол до поиска) | молчаливый запуск | нельзя менять протокол после результатов |
| OpenAlex как основной поиск | № 4 | только websearch | websearch не воспроизводим и не даёт метаданные пачкой |
| DataCite для датасетов | № 7 | искать слово dataset в статьях | даёт DOI, license и publisher |
| Q1/Q2 только с указанием источника, года и категории | № 5 | «Q1 по названию журнала» | квартиль зависит от категории/года |
| A* по ICORE, с кэшем | № 6 | ручной список | список устаревает и не проверяем |
| Синтез — LLM по аннотациям, с DOI-доказательствами | PRISMA | автоматический вывод по ключевым словам | ключевые слова дают ложные темы |
| HTML без сети | запрос пользователя; dashboard-практика | CDN-графики | не открывается офлайн |

## 7. Открытые вопросы для ревью

1. Разрешать ли preprint-серверы в основной выдаче или только как отдельную
   пометку?
2. Считать ли Q1/Q2 по лучшей категории журнала или по категории, ближайшей
   к направлению? В дизайне — по категории, ближайшей к теме; при отсутствии
   соответствия — «Q1/Q2 (best category)».
3. Хранить ли полные аннотации в HTML или только сворачиваемые фрагменты?
4. Нужен ли отдельный режим «только новые датасеты» без статей?
