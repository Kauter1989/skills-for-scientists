# Метрики и метки качества

Нормативный документ `ai-market-landscape`. У каждой метрики есть формула,
единица, уровень качества и ограничение. Метрика без источника и метода не
публикуется.

## 1. Уровни качества

| Метка | Значение | Пример |
|---|---|---|
| `measured` | число прямо в источнике | компания подтверждена сайтом и каталогом |
| `derived` | расчёт поверх `measured` | доля услуг, GAP, Gini |
| `estimated` | вывод по публичным материалам | домен компании по описанию линейки |
| `expert` | решение аналитика без публичного подтверждения | страна штаб-квартиры из курируемой таблицы |
| `missing` | источник не подтверждает | нет года основания |

Правило: если хотя бы одно слагаемое метрики `missing`, метрика получает
`missing`, а не ноль. Ноль — это измеренный факт «нет».

## 2. Метрики когорты

| ID | Формула | Единица | Качество | Ограничение |
|---|---|---|---|---|
| `AIC` | число компаний когорты без `needsReview` | компаний | `measured` | не является объёмом рынка |
| `PSS` | число компаний с `pak != none` / `AIC` × 100 | % | `derived` | класс ПАК подтверждается описанием линейки |
| `UDI` | число доменов с хотя бы одной компанией / 9 × 100 | % | `derived` | домен присваивается с ошибками |
| `UID` | число услуг с хотя бы одной компанией / 9 × 100 | % | `derived` | услуги автособранных записей — значение по умолчанию |
| `GINI` | коэффициент Джини по счётчикам ролей | коэф. | `derived` | при двух ролях неинформативен |
| `FOUNDED_COV` | компаний с годом основания / `AIC` × 100 | % | `derived` | ниже 50% — динамика по годам недоступна |

### Джини

```
G = (2 * Σ i·x_i) / (n * Σ x_i) - (n + 1) / n,  x — отсортированные по возрастанию счётчики
```

Используется как индикатор концентрации (Shen и др., 2025 сообщают Gini
0,938 для когорты проектов). При малой когорте значение нестабильно: в отчёте
оно публикуется вместе с `AIC`.

## 3. Метрики динамики

| ID | Формула | Качество | Когда публикуется |
|---|---|---|---|
| `DD_YEAR` | средний шаг накопленного числа компаний по годам основания | `estimated` | не менее 3 точек и `AIC ≥ 10` |
| `NEW` / `DROPPED` | разность множеств id двух снимков | `measured` | при наличии предыдущего снимка |

`DD_YEAR` не является числом выходов компаний на рынок: годом основания
считается то, что подтверждает источник, а выбывание компаний доступно только
через сравнение снимков.

## 4. Метрики разницы рынков

| ID | Формула | Качество | Условие |
|---|---|---|---|
| `GAP` | `share_WORLD - share_RF` | `derived` | не менее 10 компаний в каждой когорте |
| `GAP_MISSING` | области с `share_RF = 0` и `count_WORLD ≥ 3` | `derived` | — |
| `ROLE_GAP` | роли, встречающиеся в мире и отсутствующие в РФ | `measured` | — |

Пороги 10 и 3 — продуктовое решение автора, зафиксированное в профиле:
`Gap threshold`. Изменение порога — изменение отчёта и фиксируется в профиле.

## 5. Что отчёт обязан показывать

1. Для каждой когорты — количество компаний и все шесть метрик с метками.
2. Число записей, ожидающих проверки, и их источники.
3. Для каждой компании — источник (URL) и метку качества.
4. Для разницы — знак и единицу «пункты процента».
5. Все ограничения из `warnings` снимка.
