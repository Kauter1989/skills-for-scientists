# Палитры, шрифты и шаблоны (извлечено из рабочих презентаций)

Две фирменные схемы получены разбором приложенных шаблонов. Пресеты
реализованы в `scripts/build_deck.py` (`--brand opi|harness`); при работе
«из шаблона» цвета наследуются из файлов шаблонов автоматически.

## Пресет `opi` — отчёт о результатах НИР (шаблон ОПИ19.05)

Холст **10 × 5,625"** (компактный 16:9). Гамма: глубокий синий + зелёный
акцент; спокойный «инженерный» вид.

| Роль | HEX | Применение |
|---|---|---|
| ink (основной) | `002060` | заголовки, шапки таблиц, первая серия диаграмм |
| ink2 | `1F3864` | подзаголовки, лид-абзацы |
| ink-средний | `31538F`, `333F70` | второстепенные заголовки, корпусной текст темнее muted |
| text | `262B3A` | основной текст |
| muted | `64748B` | подписи, источники, колонтитулы, оси |
| accent | `1B6B3A` | положительные эффекты, зелёная серия |
| accent2 | `297FD5` | вторичный акцент (из темы), номера разделов |
| panel | `E5E9F0` | подложки панелей, сетки диаграмм |
| panel2 | `F4F7FC` | зебра таблиц, карточки |
| bg_dark | `002060` | титул, разделители, финал |
| on_dark / on_dark_muted | `FFFFFF` / `C9D6F5` | текст на тёмном |

Серии диаграмм (порядок): `002060, 297FD5, 5AA2AE, 1B6B3A, 7F8FA9, 9D90A0`.

Шрифты: тема шаблона — **Inter / Inter SemiBold**; в слайдах встречаются
Calibri, Arial, Aptos. Для генерации с нуля пресет использует
**Calibri** (метрологически безопасен при рендере и гарантированно есть
в Office); если Inter установлен у получателя — переопределите в
спецификации: `"fonts": {"heading": "Inter SemiBold", "body": "Inter"}`.
Aptos не использовать (ненадёжная замена при QA, отсутствует в старых Office).

Особенности шаблона: 11 именованных макетов (перечень —
`slide-patterns.md`), фон мастера — белый (lt1), нумерация страниц
(плейсхолдер sldNum), подписи авторов проектов под содержанием слайда.

## Пресет `harness` — аналитика для руководства (шаблон Harness/AI OS)

Холст **13,333 × 7,5"** (широкий 16:9, LAYOUT_WIDE). Гамма «Midnight
Executive»: тёмно-синий чернильный + терракотовый акцент + шалфейный
вторичный.

| Роль | HEX | Применение |
|---|---|---|
| bg_dark / text | `1B1E2B` | фон титула/разделителей/финала; основной текст на светлом |
| ink | `1E2761` | заголовки, доминирующий цвет (60–70 % веса) |
| ink2 | `2C3A85` | вторичные тёмно-синие элементы |
| accent | `B85042` | терракота: предупреждения, риски, акцентные числа |
| accent2 | `7C9885` | шалфей: третичные элементы, «спокойные» серии |
| muted | `5B5F6E` | подписи, оси, источники |
| panel | `E7E9F2` | подложки, сетки |
| panel2 | `EAF1FB` | карточки, зебра |
| доп. светлые | `C9D6F5`, `CADCFC`, `F0DAD6`, `D8DAE2` | светло-синие/пудровые подложки блоков |
| gold | `B8935A` | редкий акцент (награды, milestones) |

Серии диаграмм (порядок): `1E2761, B85042, 7C9885, 5A6B87, B8935A, 2C3A85`.

Шрифты: **Cambria** (заголовки, serif — «научная» подача) + **Calibri**
(корпус). Оба входят в безопасный список (метрики совпадают при рендере
в LibreOffice/PowerPoint — QA предсказуем).

Особенности шаблона: «сэндвич» — тёмный титул, светлое содержание, тёмный
финал; кастомные цветные подложки блоков; ссылки на источники
непосредственно в заголовках слайдов; строки цитирования (arXiv, DOI)
на финальном слайде; дорожные карты «6/12/36 месяцев».

## Правило доминирования (60–30–10)

- ~60 % визуального веса — ink/фон (тёмно-синий, белый);
- ~30 % — panel/muted (подложки, вторичный текст);
- ~10 % — accent (терракота/зелёный): только смысловые акценты —
  ключевые числа, предупреждения, финальная веха таймлайна.
Запрещено: равновесие всех цветов радуги; цветной «шум» из 5+ оттенков
на одном слайде вне диаграммы.

## Типографическая шкала

| Роль | Базовый режим | Проектор (`--projector`) |
|---|---|---|
| Заголовок слайда | 24–30 pt | 27–32 pt |
| Основной текст | 12–14 pt | 15–16 pt |
| Таблица | 10,5–11 pt | 14 pt |
| Source / footer | 9–10 pt | 14 pt |
| KPI-значение | 34–44 pt | 38–48 pt |

Минимум для проектора — 14 pt для **всех** runs. При `--min-font 14`
высоты карточек, таблиц и панелей пересчитываются от фактического кегля;
не полагайтесь на простое «зажатие» шрифта без перекомпоновки.

## Как использовать шаблоны

- `templates/rnd-report-opi.pptx` — **донор макетов** для отчётов НИР:
  дублируйте слайд нужного архетипа и заменяйте содержимое (маршрут
  «Из шаблона» в SKILL.md). Содержит реальный проект-пример — перед
  выдачей результата убедитесь, что заменены ВСЕ тексты, подписи авторов
  и таблицы (проверка: extract_text + grep по фамилиям/названиям).
- `templates/exec-wide-harness.pptx` — **референс композиции** широких
  слайдов для руководства (таймлайны, сравнительные таблицы, стек-схемы);
  при необходимости донор широкоформатных слайдов.
- Шаблоны можно заменить корпоративными: положите свой `.pptx` в
  `templates/` и укажите его в команде; пресеты цветов в build_deck.py
  расширяются добавлением записи в словарь `BRANDS`.
