# Паттерны слайдов (архетипы компоновки)

Извлечены из разбора двух рабочих шаблонов:
`templates/exec-wide-harness.pptx` (аналитика для руководства, 16:9 широкий) и
`templates/rnd-report-opi.pptx` (отчёт о результатах НИР, 11 именованных
макетов). Каждый архетип имеет тип в `scripts/build_deck.py` и/или макет
в шаблоне ОПИ.

Правило выбора: **не более 3–4 слайдов одинакового архетипа подряд**;
чередуйте текст/данные/схемы. Текстовых слайдов без визуального элемента
(диаграмма, таблица, схема, KPI) — не более одного на раздел.

---

## 1. Титул (`type: title`)

Тёмный фон, крупный заголовок (30–40 pt), подзаголовок одной фразой,
блок метаданных внизу: автор, должность, подразделение, месяц и год.
Ключевое слово над заголовком — жанр документа («Аналитический отчёт»,
«Результаты научно-исследовательских проектов»).

Прототип: Harness slide 1 — «Harness: фундамент AI OS…», подзаголовок-
определение, «Сентябрь 2026 / Руководитель по технологическому развитию /
Отдел перспективных исследований».

## 2. Ключевые положения (`type: summary`)

3–5 пронумерованных тезисов в карточках (сетка 2×2 или 2×3):
жирная формулировка вывода + 1–2 предложения обоснования. Тезисы должны
читаться как связный конспект всего отчёта. Второй слайд документа.

## 3. Разделитель раздела (`type: section`)

Тёмный фон, крупный номер раздела (01, 02…), наименование раздела,
опционально один поясняющий тезис приглушённым цветом.
Прототип: макет «Section header» шаблона ОПИ; разделители Harness
(«Хронология…», «Экосистема…»).

## 4. Содержательный слайд (`type: content`)

Рабочая лошадка отчёта. Заголовок-вывод, опционально лид-абзац (2–3 строки,
цвет ink2), 1–2 колонки маркированных пунктов. Допустимые усиления:
- **статистическая панель справа**: крупное число + подпись (прототип —
  Harness slide 5, «65 %» в панели);
- **схема/изображение** в одной из колонок вместо текста;
- строка источника внизу.

Прототип плотности: ОПИ slide 2 — блоки «Актуальность и значимость /
Разработанное решение / Перспективы развития» + панель «РЕЗУЛЬТАТЫ И
МЕТРИКИ» + подписи авторов. Один слайд = законченный рассказ о проекте.

## 4a. Три-четыре колонки-аспекта (`type: cards`)

Три равные карточки для параллельных сущностей: треков, аспектов,
проекций. В каждой — номер, заголовок, подзаголовок-аспект, 3–5 пунктов
и нижний блок «Компоненты/Вклад». Внизу — тёмная полоса-вывод (`band`).
Прототип: слайд «Логика формирования треков» (три аспекта AI OS).

Правило: карточки одной высоты; нижние блоки выровнены; текст не
заходит в нижнюю полосу; заголовок карточки — не более двух строк.

## 4b. Матрица (`type: matrix`)

Строки — слои/этапы, колонки — контрольные точки/варианты. Шапка тёмная,
первая колонка — названия, остальные ячейки центрированы. Для матрицы
«слой спецификации × КП-1/КП-2/КП-3».

## 5. Метрики и достижения (`type: kpi`)

Заголовок-вывод, ряд из 2–4 карточек: крупное число (34–44 pt, цвет
роль-зависимый: базовый показатель — ink, положительный эффект — accent,
вторичный — accent2), подпись-наименование показателя, опционально дельта
(«+4 п.п. к плану»). Ниже — панель «Значение для бизнеса» или
«Интерпретация» (1–3 предложения).

Прототип: ОПИ slide 10 — «-80 % / -50 % / до 50 элементов» + блоки
«КЛЮЧЕВЫЕ ДОСТИЖЕНИЯ», «ЗНАЧЕНИЕ ДЛЯ БИЗНЕСА», «ОГРАНИЧЕНИЯ ТЕКУЩЕГО
ЭТАПА»; макет «Big number».

## 6. Данные: диаграмма + интерпретация (`type: chart`)

Нативная диаграмма PowerPoint занимает 60–70 % ширины; справа — панель
«главный вывод» (жирным, на подложке) + 2–4 пункта интерпретации.
Обязательны: заголовки осей с единицами, подписи значений, источник.
Выбор типа диаграммы — см. `data-visuals.md`.

Прототип: ОПИ slides 6–9 (доли и характеристики проектов, таблицы 8 шт.,
графические фреймы 4 шт.).

## 7. Сравнительная таблица (`type: table`)

Таблица: тёмная шапка, белый/светлый зебра-корпус, первая колонка —
наименования (полужирные), числовые колонки выровнены по правому краю.
Не более 8 строк данных; при большом объёме — разбивка или переход
к диаграмме. Справа или снизу — 2–4 вывода из таблицы. Таблица
выравнивается по верху; для проектора кегль ≥ 14 pt.

Прототип: Harness slide 7 — сравнение платформ по колонкам
(«Siemens + NVIDIA», «Alphabet», «OpenAI»…) с итоговой строкой-выводом.

## 8. Хронология / дорожная карта (`type: timeline`)

Горизонтальная линия, 3–6 вех: период сверху (жирный, head-шрифт),
карточка содержания снизу. Финальная веха выделяется акцентным цветом.
Карточки — одинаковой высоты; блок выравнивается по верху, чтобы не
возникало пустоты под заголовком.
Для планов — горизонт 6/12/36 месяцев (прототип: Harness slides 18–19 —
«Результаты через 6/12/36 месяцев» с конкретикой по срокам).
Для истории вопроса — годы + событие + значение (Harness slide 6,
«2022–2026: ReAct → MCP → …»).

## 9. Выводы и рекомендации (`type: closing`)

Тёмный фон (замыкает «сэндвич»: тёмный титул → светлое содержание →
тёмный финал). Две колонки: «ВЫВОДЫ» (что установлено) и «РЕКОМЕНДАЦИИ»
(какое решение требуется: одобрить, профинансировать, согласовать) —
пронумерованные списки по 2–4 пункта.

## 10. Источники (`type: refs`)

Нумерованный список, кегль 11–12, формат — ГОСТ-подобный или краткий
библиографический (см. style-guide.md § 4). Включает внешние публикации,
внутренние протоколы, данные, использованные в диаграммах.
Прототип: Harness slide 20 — «Jimenez et al. — SWE-bench,
arXiv:2310.06770 (10.2023)».

## Макеты шаблона ОПИ (для маршрута «из шаблона»)

| Макет | Назначение | Плейсхолдеры |
|---|---|---|
| slideLayout1 «Title slide» | титул | title, subtitle |
| slideLayout2 «Section header» | разделитель | title, body |
| slideLayout3 «Title and body» | основной слайд | title, body(idx1), sldNum |
| slideLayout4 «Title and two columns» | две колонки | title, body×2 |
| slideLayout5 «Title only» | заголовок + свободная композиция | title |
| slideLayout6 «One column text» | плотный текст | title, body |
| slideLayout7 «Main point» | один крупный тезис | title, sldNum |
| slideLayout8 «Section title and description» | раздел с описанием | title, body |
| slideLayout9 «Caption» | подпись к визуалу | title, body |
| slideLayout10 «Big number» | крупный показатель | title, body(idx1), sldNum |
| slideLayout11 «Blank» | схемы, нестандартные композиции | — |

Порядок работы с шаблоном — см. SKILL.md, маршрут «Из шаблона».
